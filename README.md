# 🌌 Atis Paradox｜导向

一个单文件、零依赖、自带系统级干预的个人发展终端。
把六维矛盾复盘、带标签分组的周计划、GitHub 风格贡献图、发展时间轴、临时备忘，以及一只会对你进行健康干预的**大姐姐桌宠**，全部塞进了一个 HTML 里。

数据完全储存在浏览器的 `localStorage` 中，不联网、不上传、不依赖任何后端，随时打开即可使用。

---

## ✨ 核心特性

### 📡 六维矛盾雷达
- **多维度洞察**：精神、事业、财富、能力、健康、家庭六个维度，每个维度可记录核心矛盾并标记「低 / 中 / 高」紧迫度。
- **实时雷达图**：内联 SVG 手绘正六边形，紧迫度变化即时重绘。独立「主要矛盾」卡片以徽章形式展示，不破坏雷达图阵型。
- **一键归档**：可附带关键词将当前状态快照保存至时间轴。

### 🗓️ 周计划与任务库
- **标签分组系统**：任务支持创建、修改、全局删除自定义标签。表格自动按标签分组，无标签任务固定沉底，组内完美保持优先级/时间排序。
- **灵活循环机制**：新建任务时可选择「单次」或「每周循环」，过期单次任务自动灰显。
- **加权评分**：按任务优先级（重要且紧急=4，重要不紧急=3...）动态计算「今日评分」，进度条同步反馈。
- **等高备忘面板**：右侧备忘列表与左侧周计划面板**严格等高**，内部独立滚动，绝不破坏全局布局。

### 🟩 Contribution 贡献日历
- **过去全览**：类似 GitHub 的贡献图，展示历史每日评分。
- **只增不改**：每天结束的评分会永久保存，绝不因每周重置而丢失。
- **实时悬停**：鼠标悬停方块弹出气泡，显示具体日期与评分，今日数据实时计算。

### 🕰️ 发展时间轴
- **阶段标记**：插入 🚩 Flag 标记大阶段，后续快照自动归属。
- **精准检索**：支持按关键词搜索、按时间正序/倒序排序、按 Flag 阶段多选筛选。
- **节点管理**：快照可随时标星收藏或删除；删除阶段时，快照不会丢失，而是自动转为「未归属阶段」。

### 🐋 大姐姐桌宠与番茄钟（系统级联动）
- **16 个表情状态**：常驻「冷漠」形象，摸鱼、睡觉、被戳、拖拽各有专属表情，每 20–40 秒随机触发情绪状态。
- **强制健康干预（大姐姐模式）**：
  - **固定时间**：每天 `12:00` 强制提醒吃饭，`22:30` 强制提醒睡觉。
  - **周期节点**：早 6 点至晚 24 点，每 45 分钟触发一次「喝水/站立/运动」等周期提醒。
  - **压迫感视觉**：触发时，全屏降下深色毛玻璃遮罩，桌宠切换为「大姐姐」全身立绘（占据 70vh），必须点击确认「我知道了，这就去」才会给予拥抱并退出。
- **右键番茄钟**：右键点击桌宠呼出菜单，可开启/关闭悬浮番茄钟。
  - 支持倒计时、正计时、标准时间三种模式。
  - 层级严密：页面 < 番茄钟 < 桌宠 < 大姐姐遮罩（重叠时桌宠永远在上方）。
  - 支持直接输入时长、调整间隙、暂停与终止重置。

### 🎨 极致美学双主题
- **深色模式**：深炭蓝底 + 琥珀橙行动色 + 青瓷灰绿，深邃且宁静。
- **浅色模式**：冷灰白底 + 克莱因科技蓝 + 焦糖橙点缀，极具理性与高效率感。
- **全局毛玻璃**：所有模块均采用 `backdrop-filter` 半透明玻璃质感，底层映射出您自定义的朦胧壁纸，空间纵深感拉满。

## 🚀 快速开始

### 1. 本地预览
无需构建、无需安装依赖，直接双击 `paradox.html` 即可在浏览器中运行。
如果浏览器对本地文件有严格限制，可在目录下启动本地静态服务器：
```bash
# Python 3
python3 -m http.server 8080
# 访问 http://localhost:8080/paradox.html
```

## ⚙️ 交互技巧

- `Ctrl + Shift + H`：一键隐藏 / 显示桌宠（隐藏时停止所有动作与调度）。
- **右键桌宠**：呼出菜单，打开番茄钟。
- **大姐姐强退机制**：当大姐姐降临时，点击遮罩外部、按 `Esc`、滚轮滑动均无效，必须点击中央的确认按钮方可返回。
- **调试模式**：在 URL 后添加 `#whale-pet-debug`，可在浏览器控制台输入：
  - `WhalePet.debug.forceEmotion('疑惑')` 强制切换表情。
  - `WhalePet.debug.forceAction('trip')` 强制触发摔倒。
  - *注意：大姐姐干预属于特殊状态，需在测试中直接修改代码时间或模拟系统时间触发。*

## 🧠 技术说明

### 数据存储
- **主展板**：`localStorage['atis.paradox.v1']`
- **桌宠与番茄钟**：`localStorage['whale-pet:v1:']`（前缀隔离）
- **重置**：如需清空所有数据，请在浏览器控制台执行 `localStorage.clear()` 并刷新。

### Z-Index 层级矩阵
为了保证极致的交互体验，系统内部严格遵循以下层级划分：
- `0`：页面正常元素
- `2147483645`：番茄钟组件
- `2147483646`：桌宠宿主节点 (`#whale-pet-host`)
- `2147483647`：右键菜单 / 大姐姐干预遮罩 / 全局提示

### 后台节流防御
大姐姐的健康提醒未采用简单的 `setTimeout`，而是采用**“系统绝对时间戳比对”**。即使页面被挂在后台数小时，切回前台时也只会补弹最近的一个提醒，绝不会出现弹窗连环轰炸。

## 📋 已知限制
1. **纯本地应用**：数据不同步，清除浏览器缓存会导致数据丢失，请定期备份。
2. **单次任务过期**：单次循环任务过期后会在任务表格中灰显并标为“已过期”，需手动清理。
3. **无服务端**：大姐姐的“反馈”依赖用户点击“我知道了”按钮来确认，无法进行真正的文本对话。
