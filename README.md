# Atis Paradox｜导向

一个单文件、零依赖的个人发展展板。把六维矛盾复盘、周计划、发展时间轴、临时备忘，和一只会陪你摸鱼的鲸鱼娘桌宠，全部塞进一个 HTML 里。

数据全部存在浏览器 `localStorage`，不联网、不上传、不依赖任何后端。

---

## 功能特性

### 📡 六维矛盾雷达
- 精神、事业、财富、能力、健康、家庭六个维度，每个维度可写当前最核心的矛盾，并标记「低 / 中 / 高」三档紧迫度。
- 右侧 SVG 手绘正六边形雷达图，紧迫度变化即时重绘，数据面随主题明暗适配。
- 六维下方独立「主要矛盾」卡片，复用同样 UI，但不进入雷达六轴，紧迫度以徽章展示。
- 一键保存本次快照，附关键词归档。

### 🗓️ 周计划与 Contribution
- 周一至周日切换查看，今日任务面板**全部平铺展示**，不出现内部滚动条。
- 今日评分按优先级加权（重要且紧急 4 / 重要不紧急 3 / 紧急不重要 2 / 不重要不紧急 1），进度条与评分同步。
- 任务表格约 5 行可见，超出内部滚动，表头吸顶；支持按优先级或添加顺序排序。
- 添加任务时弹窗选择**每周循环**或**单次**，任务表格内可随时切换。
- 每周一自动保存上周日评分并清空所有任务的已完成勾选，开始新一周，无需手动操作。
- 模块内可切换到 **Contribution** 视图：GitHub 风格贡献日历，按日评分五级着色，悬停显示「日期 · 评分」，今天的评分实时计算、跨天后永久写入，不受每周重置影响。

### 🕰️ 归档时间轴
- 每次快照记录六维矛盾与紧迫度，按写入顺序排列成纵向时间轴。
- 可插入阶段标记（flag），插入后快照自动归属该阶段，直到下一个标记。
- 支持按关键词与维度文本搜索、按时间正序/倒序排序、按 flag 阶段筛选。
- 快照可标星收藏、可删除；flag 可删除，删除阶段不会删除快照，关联快照转为「未归属阶段」。
- 时间轴独立滚动，约 10 个节点可见，滑块为品牌色。

### 📌 备忘
- 临时 Todolist，支持新增、勾选完成、行内编辑（Enter / 失焦提交，Esc 取消）、删除。

### 🐋 鲸鱼娘桌宠
- 固定在视口右下角，可拖动放置，位置跨会话记忆，松手后边缘吸附。
- 16 个表情状态，`冷漠` 为常驻形象；点击、拖拽、摸鱼、睡觉、摔倒、甩出等各有专属表情。
- 独立 `emotion` 状态每 20–40 秒从剩余表情中按权重随机播放，让桌宠「有情绪」。
- 抢占式状态机，高优先级动作可打断低优先级；拖拽期间调度器挂起。
- 台词池按表情组织，带最近使用降权与深夜变体。
- 支持 `Ctrl+Shift+H` 隐藏 / 显示；隐藏时调度器与动画全部暂停。

### 🎨 双主题
- **暗色**：深炭蓝底 + 琥珀橙行动色 + 青瓷灰绿辅助色。
- **亮色**：冷灰白底 + 石墨黑文字 + 深青/藏蓝结构色 + 焦糖橙点缀。
- 支持「浅色 / 深色 / 跟随系统」三态切换，用户选择持久化。
- 标题处少量 Emoji 点缀，全页不超过 8 处。

## 快速开始

### 本地预览

无需构建、无需安装依赖，直接双击 `Function Wiki/paradox.html` 即可运行。

如果浏览器对本地文件限制较多，可在项目根目录起一个静态服务器：

```bash
# Python 3
python3 -m http.server 8080

# 或 Node.js（需已安装）
npx serve .
```

然后访问 `http://localhost:8080/Function%20Wiki/paradox.html`。

## 技术说明

### 技术栈
- 原生 HTML5 + CSS3 + JavaScript（ES2020）
- 无框架、无构建工具、无包管理器、无 CDN、无外部字体
- 雷达图与贡献图均为原生实现：雷达图用内联 SVG，贡献图用 DOM + CSS Grid
- 桌宠动画使用 Web Animations API 驱动 `transform` / `opacity`

### 数据存储
全部数据保存在浏览器 `localStorage`，两个命名空间互不干扰：

| 键名 | 内容 |
|---|---|
| `atis.paradox.v1` | 六维矛盾、主要矛盾、任务、归档、flag、备忘、主题、排序、筛选、贡献日历 |
| `whale-pet:v1:` 前缀 | 桌宠位置、显隐、静音、最后交互时间 |

> 清理浏览器站点数据会清空所有记录。重要内容建议定期截图或手动备份 `localStorage`。

### 配色体系
两套主题共享同一组 CSS 变量名，定义在 `:root[data-theme="dark"]` 与 `:root[data-theme="light"]` 下，切换主题只换值不换名。

| 角色 | 暗色 | 亮色 |
|---|---|---|
| 页面底 | `#0e1318` | `#f2f5f7` |
| 主卡片 | `#151c24` | `#ffffff` |
| 正文 | `#e6edf3` | `#1f272e` |
| 行动色 | 琥珀橙 `#f0a03c` | 深青 `#1f5f6b` |
| 点缀色 | 琥珀橙 `#ffb95e` | 焦糖橙 `#c2681a` |

亮色模式下焦糖橙只做点缀（品牌符号、雷达顶点、flag、收藏、保存按钮），大面积行动色交给深青，避免廉价感。

### 桌宠状态机简述
- 所有行为请求经过唯一出口 `PetFSM.play(action, opts)`。
- 优先级：`poke(5) > drag(4) > trip/swim/land(3) > working/hungry/wave(2) > emotion/walk/slack/sleep(1) > idle(0)`。
- 高优先级可打断低优先级；低优先级请求在高优先级播放期间直接丢弃，不排队。
- 调度器每条规则独立递归 `setTimeout`，`document.hidden` 时全部暂停。
- 调试模式：在 URL 后加 `#whale-pet-debug`，可在控制台调用：
  ```js
  WhalePet.debug.forceEmotion('疑惑')   // 强制播放指定表情
  WhalePet.debug.forceAction('trip')    // 强制播放指定动作
  WhalePet.debug.getAssets()            // 查看 16 张素材加载状态
  WhalePet.debug.getFSMLog()            // 最近 50 条状态转换
  ```

## 已知限制

1. **数据仅存本地。** 换浏览器、换设备、清理缓存都会丢失；不做云同步，也不上传任何数据。
2. **不做跨标签页同步。** 多标签页打开时各自独立运行，桌宠也各有一只。
3. **桌宠不保证绝对置顶。** 宿主页面若存在同为 `fixed` 且 `z-index` 更高的浮层，桌宠可能被覆盖。
4. **单次任务过期后保留。** 过期单次任务在任务表格中灰显并标注「已过期」，不会自动删除，需手动清理。
5. **跨多天未打开不补算贡献。** 每周重置与评分保存只在页面打开时触发，中间日期不会自动补录。
6. **桌宠为单帧立绘变换。** 动画靠 `transform` 制造生命感，不包含关节动画或帧序列；表情切换靠换图。

## 本地预览检查清单

首次运行后，建议按以下顺序确认功能正常：

- [ ] 六维紧迫度变化，雷达图实时缩放
- [ ] 添加任务弹窗出现，可选每周/单次
- [ ] 勾选今日任务，进度条与评分按权重变化
- [ ] 切换到 Contribution，看到贡献日历与悬停气泡
- [ ] 保存一次快照，时间轴出现关键词节点
- [ ] 插入 flag，再保存一次，快照自动归属该阶段
- [ ] 切换浅色/深色，刷新后保持
- [ ] 右下角出现鲸鱼娘，可拖动，点击有反应
- [ ] 控制台无报错、无网络请求
