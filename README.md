# Atis Paradox｜导向

一个**单文件、零依赖、纯前端**的个人发展展板。集成了六维矛盾雷达、周期计划与贡献热力图、发展时间轴、临时备忘，以及一位会关心你健康的“大姐姐”桌宠。

所有数据存储在浏览器 `localStorage` 中，不联网、不上传、不上云，既安全又私密。

---

## 🚀 核心特性

### 📡 六维矛盾雷达
- 精神、事业、财富、能力、健康、家庭六个维度，独立记录核心矛盾与紧迫度（低/中/高）。
- 内联 SVG 绘制的正六边形雷达图，紧迫度变化即时重绘。
- 独立「主要矛盾」卡片，不占雷达轴，以徽章形式展示。
- 支持一键归档快照，附带关键词。

### 🗓️ 周计划 & Contribution 贡献图
- **标签分组**：任务支持自定义标签，自动按标签归类分组，无标签项沉底。
- **任务循环**：创建时可选择「每周循环」或「单次」，支持后续修改。
- **自动重置**：每周一自动保存上周日评分并清空任务的已完成状态。
- **Contribution 热力图**：GitHub 风格贡献日历，按每日评分五级着色。悬停显示具体分数，历史数据永久保存。
- **滚动链优化**：内部滚动条触底后，滚轮自动交接给全局页面，丝滑无卡顿。

### 🕰️ 归档时间轴
- 纵向时间轴展示所有快照与「Flag 阶段标记」。
- 支持按关键词、维度文本搜索。
- 支持按时间正序/倒序排序，支持按 Flag 阶段筛选。
- 快照可**标星**收藏、可**删除**；删除 Flag 不会丢失快照，仅将其转为「未归属阶段」。

### 📌 备忘
- 左侧周计划与右侧备忘面板**高度严格等高**。
- 内部列表支持滚动，滚动链同样不阻断全局页面。

### 🐋 鲸鱼娘桌宠
- **16 个表情状态**：基于单帧图片变换，`冷漠` 为常驻形象。
- **独立情绪池**：每 20–40 秒随机触发情绪，10 个已绑定表情在池中权重降低。
- **状态机调度**：优先级抢占式调度，支持拖拽、点击、待机、摸鱼、睡觉等丰富动作。
- **台词池**：每个表情自带专属台词，带最近使用降权与深夜变体。

### 🧘‍♀️ 大姐姐健康干预
- **强制关怀**：每 45–90 分钟随机触发一次。
- **视觉冲击**：全屏黑底毛玻璃遮罩，大姐姐形象占据 70% 屏高。
- **严厉又温柔**：内置 6 条健康提醒（水、睡眠、久坐、蔬菜、蛋白、有氧），根据状态随机播放。
- **闭环反馈**：用户点击确认后，大姐姐给予“真乖，抱抱~”的反馈，随后淡出恢复小桌宠。

### 🎨 美学与 UI
- **深浅双主题**：
  - 深色：深炭蓝底 + 琥珀橙行动色 + 青瓷灰绿辅助色。
  - 浅色：冷灰白底 + 科技蓝主色 + 焦糖橙点缀。
- **毛玻璃质感（Glassmorphism）**：全局面板半透明，叠加 `backdrop-filter`。
- **朦胧壁纸**：底层引入 `Wallpaper.png` 并进行适度模糊，营造空间纵深感。

## 🛠️ 快速开始

无需安装环境，直接双击 `02_Function Wiki/paradox.html` 即可运行。

若需通过本地服务器预览（避免某些浏览器对本地文件的限制）：

```bash
# Python 3
python3 -m http.server 8080

# 或 Node.js
npx serve .
```
访问 `http://localhost:8080/02_Function%20Wiki/paradox.html`。

## ⚙️ 技术说明

- **技术栈**：原生 HTML5、CSS3、ES2020，无任何框架/依赖/CDN。
- **状态机**：内置抢断式 `PetFSM`，状态优先极：`intervention(6) > poke(5) > drag(4) > trip(3) > working(2) > idle(0)`。
- **数据存储**：`localStorage` 键 `atis.paradox.v1`（业务数据）与 `whale-pet:v1:`（桌宠数据）。
- **毛玻璃**：广泛使用 `backdrop-filter: blur(16px)`。移动端 `fixed` 定位组件使用伪元素规避 `backdrop-filter` 带来的 `containing block` 陷阱。
- **调试指令**：
  在浏览器控制台使用：
  - `WhalePet.debug.forceEmotion('疑惑')`：强制播放指定表情。
  - `WhalePet.debug.forceIntervention()`：强制触发大姐姐干预。
  - `WhalePet.debug.getAssets()`：查看素材加载状态。

## ⚠️ 已知限制

1. **数据仅存于当前浏览器**，清理缓存会丢失所有记录，建议定期截图存档。
2. **不做跨标签同步**，多标签页打开时各自独立。
3. **桌宠不可跨屏拖拽**，边界钳制在原浏览器视口内。
4. **大姐姐反馈为固定闭环**，当前版本不包含真实语言模型对话。
